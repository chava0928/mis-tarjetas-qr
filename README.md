# 🎫 Generador Profesional de Tarjetas QR
Herramienta para crear tarjetas de presentación digitales personalizadas, con código QR directo, fotos, datos de contacto y redes sociales.

## 🚀 Características
- Diseño elegante y adaptable a celulares y computadores
- Fotos integradas dentro del código, sin depender de carpetas externas
- Botón para guardar el contacto directamente en la agenda
- Íconos oficiales de redes sociales
- Vista previa en tiempo real antes de generar el código

## 🛠️ ¿Cómo funciona?
1. Llena los datos y sube las fotos en la herramienta
2. Genera y descarga tu código QR
3. Copia el código de la tarjeta y guárdalo con el nombre del cliente
4. Sube los archivos a GitHub y compártelos con tu cliente
